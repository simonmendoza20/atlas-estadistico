# Atlas Estadístico

Biblioteca pública e interactiva de visualización estadística en español.

## Funcionalidades

- 36 ejemplos interactivos en 12 familias.
- Búsqueda y filtros por nivel y familia.
- Exportación de gráficos como PNG.
- Laboratorio experimental para CSV local (parser simple, no adecuado para CSV con comillas complejas).
- Datos simulados y ejemplos educativos. Algunas técnicas avanzadas son representaciones ilustrativas, no estimaciones calculadas.

## Publicación

En **Settings → Pages**, seleccionar **Deploy from a branch**, rama **main** y carpeta **/(root)**. La URL será https://simonmendoza20.github.io/atlas-estadistico/ cuando GitHub Pages termine de desplegar.

## Tecnología

HTML, CSS, JavaScript y Plotly.js vía CDN. No requiere servidor ni compilación. Los datos CSV se procesan localmente en el navegador.
